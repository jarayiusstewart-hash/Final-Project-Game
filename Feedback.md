# Hollowlight — Testing Session 1 Feedback

## Feedback Summary

Testing Session 1 identified three main areas for improvement: visual clarity, flame navigation, and cave lighting.

Feedback was gathered from classmates during playtesting. These were the three main issues reported.

## 1. Visual Clarity
**Feedback:** Players had difficulty recognizing movement because the cave surfaces lacked visible textures.

**Decision:** Fix now — High Priority

**Action Taken:** Added rock textures to the cave environment to make player movement easier to recognize.

**Status:** Fixed

## 2. Flame Navigation
**Feedback:** The guiding flame had difficulty navigating toward the objective.

**Decision:** Fix now — High Priority

**Action Taken:** Improved the flame's navigation using Unity's NavMesh system.

**Status:** Fixed

## 3. Cave Lighting
**Feedback:** The cave needed to be darker to reinforce the atmosphere and importance of the guiding flame.

**Decision:** Fix now — Medium Priority

**Action Taken:** Adjusted cave lighting to create a darker environment.

**Status:** Fixed

## Beta Decisions

All three major feedback issues were prioritized for the Beta milestone and addressed.

No additional gameplay features will be introduced after Beta content lock. Remaining development will focus on bug fixes, balancing, testing, and polishing the existing experience.

## Testing Results

The updated build was tested after implementing these changes. Player movement, flame navigation, and the objective system were confirmed to be working.

The updated browser build is available on itch.io.
